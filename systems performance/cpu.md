# CPU Observability 

1. `uptime` — Shows system uptime and load averages.
2. `vmstat` — Shows CPU, memory, swap, and I/O stats.
3. `mpstat` — Shows per-CPU usage statistics.
4. `sar` — Shows historical system activity stats.
5. `ps` — Lists running processes.
6. `top` — Shows live process and CPU/memory usage.
7. `pidstat` — Shows per-process CPU, memory, and I/O stats.
8. `time`, `ptime` — Measures command execution time.
9. `turbostat` — Shows CPU frequency, power, and C-state stats.
10. `showboost` — Shows CPU turbo/boost behavior.
11. `pmcarch` — Shows CPU performance counter architecture info.
12. `tibstat` — Shows InfiniBand adapter status.
13. `perf` — Profiles CPU events and kernel/user activity.
14. `profile` — Samples stack traces for profiling.
15. `cpudist` — Shows CPU time distribution as a histogram.
16. `runqlat` — Shows scheduler run queue latency.
17. `runqlen` — Shows scheduler run queue length.
18. `softirqs` — Shows software interrupt activity.
19. `hardirqs` — Shows hardware interrupt activity.
20. `bpftrace` — Runs eBPF tracing scripts.
